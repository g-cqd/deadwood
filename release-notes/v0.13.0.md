# deadwood 0.13.0 (from 0.12.0)

Wave 2 of the analyzer release train (analyzerkit tag `analyzerkit-wave-2`). deadwood reads the index through
analyzerkit's `IndexQueries` (analyzerkit 0054) and collects per-file facts with analyzerkit's `SymbolFacts`
(analyzerkit 0055). On maintastic, reports with and without its Xcode store are byte-identical to 0.12.0, stderr
included, and so is deadwood's own.

## Cache

Declarations now carry their name's position, so the cache is about 2% larger (35.8 to 36.5 MB on maintastic). A 0.12
cache is rebuilt once, as with any new version. The JSON coding of the facts, unused since protobuf replaced it, is
gone, and AemiJSON is no longer linked into the tool's core.

## Findings that may appear

- With `--index-store-path` only: findings in a corpus whose path the store records through a symlink (`/var` for
  `/private/var`). Index occurrences now come back in the corpus's spelling, so the store's facts reach those files.

## Findings that may disappear

- With `--index-store-path` only, in the same case: declarations that the index now shows to be used.
