# deadwood 0.15.0 (from 0.14.2)

deadwood moves its copies onto analyzerkit: the suppression directive's coding, `Fingerprint` and `FindingBaseline`, the embedding providers (`SemanticEmbedding`, roadmap 0028) and the report renderers. It is pinned to aemi `8087a01`, AemiJSON `60b3a5c`, AemiRegex `2cccb99`, AemiProtobuf `7b96250`, analyzerkit `b15fdbe`. The analyzer is unchanged: its findings are identical to 0.14.2.

The xcode, JSON and SARIF renderers and the summary line are now analyzerkit's `ToolReportFormat`, replacing this tool's copy (analyzerkit roadmap 0067, step 4). Their output matched the previous build byte for byte on the fixtures and on the other tools' `Sources`, cold and warm, with a baseline written and applied. One thing moved: the run that "analyzed nothing" (SARIF's invocation failure, exit 70) counts the unique paths of files skipped whole, so a file degraded twice is not two files.

Failure texts of the embedding providers' fallback paths (`--experimental-embeddings`, `--embedding-bundle`) are unified across the tools; they appear only in the notes that explain a fallback or an error. The Hugging Face provider's output-dimension lookup by name is deadwood's, now shared.
