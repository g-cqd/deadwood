# deadwood 0.15.2 (from 0.15.0)

0.15.1 was tagged but never published: its Linux build failed in aemi's codec kernels (fixed in aemi `921fd8d`). deadwood builds on the family's current revisions: aemi `921fd8d`, AemiJSON `172164f`, AemiRegex `f59fff4`, AemiProtobuf `418182e`, analyzerkit `fb3f5d6`. They bring aemi's SIMD kernels for Base64, hex, percent-coding and byte search (aemi ADR 0025, 0026), whose answers are the same as the code they replace. deadwood's own code is unchanged; its tests and goldens pass as before.
