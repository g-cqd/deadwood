# deadwood 0.12.0 (from 0.11.2)

Wave 1 of the analyzer release train (analyzerkit tag `analyzerkit-wave-1`): deadwood on analyzerkit's shared
foundations, with a faster index path.

- Added: `--exclude-path` (it scopes the report, never the corpus), `--rules`, `--quiet`, `--verbose`,
  `--timings`, and `--define`, which says it has no effect: deadwood reads the code of every `#if` clause.
- Renamed, with the old spelling accepted until wave 3 and printing a note: `--include` → `--include-regions`,
  `--exclude` → `--exclude-regions`, `--experimental-embedding-confidence` → `--experimental-embeddings
  confidence`.
- Removed: none.

## Exit codes

- An unwritable baseline exits 74; before, 78.

## Report

- Added, optional for a reader (ADR-0017): `tool`, `version`, `runNotes` (`{code, severity, message, count, paths}`), `skippedFiles` (`{path, reason}`, the reason one of `notIndexed`, `changedSinceBuild`, `unreadable`, `degraded`), and `timings` with `--timings`.
- Nothing removed or retyped; `schemaVersion` stays 1. SARIF, baselines and fingerprints are byte-identical.
- `notes` stays, and its lines are also in `runNotes`. The count of declarations with no reference is a note only
  under `--verbose` now (analyzerkit 0024, D5).

## Configuration

- The shared `.swift-analyzers.json` (top-level shared keys, one section per tool) is read beside the tool's own file, found from a subdirectory too, nearest first (ADR-0021).
- A configuration with an unknown or repeated key now exits 78; before, it was ignored.
- `exclude` follows ADR-0008: a glob matched against the path relative to the configuration's directory.
- Production mode's test files are the `test` region (project, then content), not `Tests/` or `*Tests.swift` by
  path. `testsGlob` still overrides.

## Cache

`--cache-path` names a root directory now (ADR-0011): facts sit in sharded files under `<root>/facts/<workspace>/`, keyed by file metadata then content, and memory-mapped. Payloads are protobuf. A tool keeps 512 MiB at most and evicts the least recently used workspaces first. A v1 cache file at the same path is replaced. The default root is `~/Library/Caches/<tool>` on macOS and `$XDG_CACHE_HOME/<tool>` (or `~/.cache/<tool>`) on Linux. On a CI runner, delete the old v1 cache files once; the tool would replace them anyway.
The cache fits now. 0.11's was capped at 64 MiB and never held maintastic, so its consumer passed `--no-cache`. A
warm run skips the scan.

## Findings that may appear

- A property named like a function that a labelled call uses (`ticketTypeDescription(for:)` against a property
  `ticketTypeDescription`). The call no longer keeps the property alive (analyzerkit 0058; one on maintastic without
  an index).
- With `--index-store-path` and a store that covers none of the analyzed files: the syntactic findings. Before, the
  store was opened and every finding was dropped as stale, a silent empty report; now it is refused with a note.
- `--only-from` with a CRLF or CR file: the findings it names (analyzerkit 0057).

## Findings that may disappear

- With `--index-store-path` and a partly covered store: a declaration that a file outside the store references by its
  base name is kept alive (analyzerkit 0024, D2; 36 of 126 on a maintastic run with a partial store).
